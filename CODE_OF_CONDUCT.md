# Contributor Covenant Code of Conduct

We pledge to keep participation in `substack-mcp-rs` a welcoming, harassment-free, and constructive technical community for all contributors regardless of background or identity.

Unacceptable behavior includes harassment, personal attacks, doxxing, or publishing uncoordinated live credentials or private data. Reports may be submitted confidentially to the maintainers via GitHub Security Advisories or private contact channels.
